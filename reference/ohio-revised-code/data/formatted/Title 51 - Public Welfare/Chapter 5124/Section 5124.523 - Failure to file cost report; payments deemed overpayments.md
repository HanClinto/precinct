# Section 5124.523 - Failure to file cost report; payments deemed overpayments.

**Effective:** September 29, 2013

**Latest Legislation:** House Bill 59 - 130th General Assembly

If an exiting operator required by section 5124.522 of the Revised Code to file a cost report with the department of developmental disabilities fails to file the cost report in accordance with that section, all payments under the medicaid program for the period the cost report is required to cover are deemed overpayments until the date the department receives the properly completed cost report. The department may impose on the exiting operator a penalty of one hundred dollars for each calendar day the properly completed cost report is late.
