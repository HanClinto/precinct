# Section 4509.77 - Prohibition against failure to return license.

**Effective:** April 9, 2025

**Latest Legislation:** House Bill 29 - 135th General Assembly

(A) No person shall willfully fail to return a license as required in section 4509.69 of the Revised Code.

(B) Whoever violates this section shall be fined not more than five hundred dollars, imprisoned for not more than thirty days, or both.
