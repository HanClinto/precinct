# Section 4901.01 - Definitions.

**Effective:** September 13, 2010

**Latest Legislation:** Senate Bill 162 - 128th General Assembly

As used in sections 4901.01 to 4901.24 of the Revised Code:

(A) "Public utility" has the same meaning as in section 4905.02 of the Revised Code.

(B) "Railroad" has the same meaning as in section 4907.02 of the Revised Code.
