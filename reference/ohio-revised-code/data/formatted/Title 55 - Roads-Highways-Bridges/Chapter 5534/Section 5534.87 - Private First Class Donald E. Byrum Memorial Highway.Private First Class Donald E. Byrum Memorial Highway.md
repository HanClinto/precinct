# Section 5534.87 - Private First Class Donald E. Byrum Memorial Highway.Private First Class Donald E. Byrum Memorial Highway.

**Effective:** March 23, 2018

**Latest Legislation:** Senate Bill 134 - 132nd General Assembly

In addition to any other name prescribed in the Revised Code or otherwise, the northbound and southbound lanes of state route number one hundred eighteen between the intersection of that route with Elroy Ansonia road and the intersection of that route with Beamsville-Union city road, in Darke county only, shall be known as the "Private First Class Donald E. Byrum Memorial Highway."

The director of transportation may erect markers along the highway indicating its name.
