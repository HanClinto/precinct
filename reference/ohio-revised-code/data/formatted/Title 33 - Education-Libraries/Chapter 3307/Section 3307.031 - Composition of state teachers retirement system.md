# Section 3307.031 - Composition of state teachers retirement system.

**Effective:** January 7, 2013

**Latest Legislation:** Senate Bill 342 - 129th General Assembly

The state teachers retirement system shall consist of the STRS defined benefit plan and the STRS defined contribution plan.
