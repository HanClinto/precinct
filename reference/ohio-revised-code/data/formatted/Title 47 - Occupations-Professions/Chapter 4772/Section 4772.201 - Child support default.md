# Section 4772.201 - Child support default.

**Effective:** April 9, 2025

**Latest Legislation:** Senate Bill 95 - 135th General Assembly

On receipt of a notice pursuant to section 3123.43 of the Revised Code, the state medical board shall comply with sections 3123.41 to 3123.50 of the Revised Code and any applicable rules adopted under section 3123.63 of the Revised Code with respect to a license to practice as a certified mental health assistant issued under this chapter.
