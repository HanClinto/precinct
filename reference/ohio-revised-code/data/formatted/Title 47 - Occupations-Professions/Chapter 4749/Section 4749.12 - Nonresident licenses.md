# Section 4749.12 - Nonresident licenses.

**Effective:** December 29, 2023

**Latest Legislation:** Senate Bill 131 - 134th General Assembly

The director of public safety shall issue a license as a private investigator, security guard provider, or as a private investigator and a security guard provider in accordance with Chapter 4796. of the Revised Code to a person if either of the following applies:

(A) The person is licensed as a private investigator, security guard provider, or as a private investigator and a security guard provider in another state.

(B) The person has satisfactory work experience, a government certification, or a private certification as described in that chapter as a private investigator, security guard provider, or a private investigator and security guard provider in a state that does not issue that license.
