A collection of scripts and tools for helping people get involved with politics via the Precinct Strategy.

Open-source. Empowered. Transparent. Deploys via Github Pages.

## Reference library

The GitHub Pages site publishes a browseable reference library. The first
collection is the Ohio Revised Code, focused on Title 35 - Elections, with a
chapter/section browser, search, and structured cross-reference metadata.

The formatted ORC collection is also published as a ZIP release asset named
`ohio-revised-code-title-35.zip` on the `orc-title-35-latest` release.
